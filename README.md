**CORE-ML** es un sistema web interactivo para la gestión integral de inventarios, control de stock y registro rápido de ventas, equipado con un módulo de seguridad y autenticación para usuarios autorizados.

🌐 **Demo en vivo:** [control-inventario-ventas.netlify.app](https://control-inventario-ventas.netlify.app/)

## ✨ Características Principales

* **📊 Control de Inventario:** Gestión ágil de catálogo de productos, existencias y flujo de stock.
* **🧾 Módulo de Ventas:** Registro rápido e interactivo de transacciones comerciales.
* **🔒 Módulo de Seguridad:** Control de acceso e interfaz de autenticación para personal autorizado.
* **📱 Interfaz Web Responsiva:** Diseño optimizado para operar con fluidez desde cualquier navegador o dispositivo.

---

## 🛠️ Tecnologías Utilizadas

* **Frontend:** HTML5, CSS3, JavaScript (ES6+)
* **Seguridad & Autenticación:** Módulo de validación web integrado
* **Despliegue & Hosting:** Netlify
* **Control de Versiones:** Git & GitHub
